# 005 · Dad Joke Generator

**AppADay** · App #005 · Category: A (AI-Powered)

Enter at your own risk. This app uses the Claude API to generate fresh, original dad jokes on demand. The punchline is hidden until you're ready — because the beat before the groan is half the joke. A groan meter scores each joke from 1 to 100.

## What it does

Click the button. Claude generates a brand-new dad joke. The setup appears first. You reveal the punchline when ready. The groan meter fills accordingly.

## Stack

- HTML / CSS / Vanilla JS
- Claude API (`claude-sonnet-4-20250514`) for joke generation
- Structured JSON response parsing
